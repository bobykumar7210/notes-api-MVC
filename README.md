# Notes API MVC

A simple Node.js Express project built with the MVC pattern for managing notes.

## Features
- Create, read, update, and delete notes
- User authentication and role-based access control
- Input validation and error handling

## Installation
```bash
npm install
```

## Run
```bash
node app.js
```
